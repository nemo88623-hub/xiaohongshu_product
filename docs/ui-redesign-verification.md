# 前端重设计与验证记录

采用 ui-ux-pro-max 的极简企业后台方向，依据原项目的六步流程调整，保留原生 HTML/CSS/JS 与本地状态。

## 已实现

- 全局设计变量：统一颜色、字号、面板、边框、间距、状态和焦点；本地图标模块，不引入外部字体或运行依赖。
- 工作台：动态概览、A/B/C 场景卡、可点击评审路径、六步能力入口。
- 管理页：全部 Agent 列表、按名称或团队搜索、新建入口。
- 详情：压缩页头，六步导航标出当前步骤；配置能力与保存/下一步集中在主面板。
- 调试：保留自由输入和系统提示词预设，支持输入框 Enter 运行，明确模拟回答。
- 评估：失败时提供返回配置入口，通过后才启用下一步；样本依据展开查看。
- 发布：灰度滑块保留，增加数字输入与“应用”；发布、审批、回退和转人工门槛保留。
- 监控：统一指标、趋势、追溯样式，图表增加可展开的数据表。
- 删除与重置：改为页面内原生 dialog，支持取消、Escape、确认和焦点返回。

## 已验证

- `node --check src/app.js`、`node --check src/icons.js`、`git diff --check`。
- `npm test`：36 项通过，0 项失败。
- 浏览器：从 B 模板新建，选择风控团队，刷新保留；管理页搜索命中。
- 浏览器：新建 B 首次失败阻断发布 → 启用规则 → 旧评估失效 → 重评 → 审批 → 发布 → 监控。

- 浏览器：C 两轮调试 → 更新 K-02 → 两轮回答包含知识引用 → 评估发布。
- 375px：调试、发布、首页、能力地图无整页横向溢出；768px 首页无溢出。桌面页面已视觉检查。
