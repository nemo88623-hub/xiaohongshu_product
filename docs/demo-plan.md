# Agent Studio Demo 增量实现记录

**目标：**在现有页面中走通「新建 → 模板 → 配置 → 调试 → 评估 → 发布 → 监控 → 迭代／回退」。

**结构：**`src/logic.js` 管理模板身份、草稿评估指纹、生产快照和发布记录；`src/app.js` 渲染工作台、管理列表、创建流程与六步工作区；`localStorage` 保存本地演示状态。

## 实现范围

- [x] 三个预置场景继续可直接体验；自建 Agent 按 `templateType` 继承场景规则。
- [x] 工作台新建入口、模板页、创建表单、管理列表与可点击的「创建」步骤。
- [x] A 策略切换改变模拟回答和离线评分；B 严重样本拦截；C 知识引用与转人工。
- [x] 代表样本展示输入、预期、实际、状态、依据和样本集版本。
- [x] 发布前变化摘要、审批人状态、评估编号、生产配置快照和带时间的记录。
- [x] A 灰度指标随 10%/50%/100% 变化；回退后隐藏新版本线上效果。
- [x] 浏览器本地保存与重置；必要状态测试和实际浏览器点击验收。

**边界：**不接真实模型、数据源、后端或并发服务。本地 4173 页面供预览；Redcowork 分享链接另行形成。
