# Agent Studio 评审 Demo

这是一个可点击的本地原型，用于展示「新建 Agent → 选择模板 → 配置 → 调试 → 评估 → 审批或灰度发布 → 监控 → 迭代／回退」。三个预置 Agent 保留为示例；新建 Agent 按所选模板走同一套规则。所有回答、指标和业务记录均为演示数据，不连接真实模型或业务系统。

## 打开

在项目目录运行 `npm run serve`，然后访问 <http://127.0.0.1:4173/>。

## 推荐体验路径

1. **新建 B：**点击「＋ 新建 Agent」选择生态守护模板，填写名称并创建；在管理列表进入新卡片。首次评估因严重样本漏判失败；启用规则后重评，完成模拟负责人审批，再发布。
2. **原有 A：**在「配置」切换推荐策略，运行调试和评估，发布到 10% 灰度；放量至 50%，在监控看模拟曝光和对比，最后回退。
3. **原有 C：**在「调试」体验两轮问答和缺知识时转人工；在「配置」导入 K-02，重新调试、评估和发布，查看引用与知识版本。

页面状态保存在当前浏览器，刷新后保留。左侧「重置演示」可删除新建 Agent 和所有演示进度。

## 检查

运行 `npm test` 检查模板创建、评估门槛、配置失效、发布记录和重置等状态路径。此本地页面仅供预览；正式提交仍需在 redcowork 生成可分享链接。
