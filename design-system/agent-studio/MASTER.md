# Agent Studio 设计规范

目标：评审者在现有原型中完成创建、配置、调试、评估、发布、监控与迭代。保留 A/B/C 模板、本地状态和发布门槛。

依据：ui-ux-pro-max 的 Minimalism & Swiss Style 匹配企业后台。采用其信息层级、对比度、焦点、语义表单和渐进展示建议。生成结果中的营销 Hero 布局不适用；product 分类两次无匹配。项目为原生 HTML/CSS/JS，使用原生控件，不引入 Tailwind 或 React。

- 视觉：暖白页面、白色面板、深灰正文、红色主要操作；A 浅珊瑚、B 淡蓝、C 淡绿作为场景标记。
- 字体：系统中文无衬线；正文 14–16px、辅助 12–13px、页面标题 28px；数值使用等宽数字。无外部字体请求。
- 间距：4/8px 基数；面板内边距 24px；圆角 12px；主体最大宽度 1280px；桌面侧栏 216px。
- 导航：侧栏只含工作台、Agent 管理、平台能力地图。六步流程仅出现在 Agent 工作区顶部，显示当前位置。
- 操作：主操作与下一步相邻；配置能力与草稿操作同面板；失败评估就近返回配置。
- 渐进展示：托管能力、样本依据、配置快照、图表明细按需展开。模拟回答和演示数据标签保持可见。
- 无障碍：SVG 图标、明确标签、可见焦点、原生下拉和滑块；滑块另有数字输入；状态用文字表达。图表提供数据表。
- 自适应：桌面双栏；平板收紧；窄屏单栏，六步导航分两行；避免整页横向滚动。

实施：统一图标与语义样式；重排首页和列表；优化六步页面；验证原有测试及浏览器关键路径、窄屏和键盘操作。业务状态机不因视觉重设计而变更。
